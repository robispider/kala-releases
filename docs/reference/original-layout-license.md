# Kala’s original layouts: free to use, adapt, and share

The newer provisional shared B01 map uses MIT, separately from this original-map dedication. See [Kala Layout licensing and availability](../layouts/kala-layout.md).

Kala’s original **Kala Jhor and Kala Goti layout maps** are dedicated to the public domain under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/), following the owner’s approval on **12 October 2026**. This covers the original key/layer maps and their original vowel-entry rules.

Use them, adapt them, share them, or include them in another keyboard implementation, including commercially, without asking permission or paying layout royalties under the CC0 terms. Read the [official legal code](https://creativecommons.org/publicdomain/zero/1.0/legalcode.en) for the complete dedication and fallback license.

This dedication applies to the project’s original layout material. It does not change the terms for Kala application code, dictionaries, datasets, third-party engines, imported/comparison layouts, brand marks, or other people’s rights. Kala software remains free to use and distribute under its existing notice; source publication is planned separately.

UniJoy/UniBijoy is not bundled. Its retained research references are outside this dedication.
