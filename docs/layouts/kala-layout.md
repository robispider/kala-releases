# Kala Goti and Kala Jhor

[Guide index](../../USER_GUIDE.md) · [Kala Goti](kala-goti.md) · [Kala Jhor](kala-jhor.md)

Kala Goti and Kala Jhor are research-designed Bangla keyboard layouts with key positions selected for lower modeled finger effort. Each has its own key map and native vowel-entry rules.

## Choose and practise

Goti uses hasant followed by a vowel sign to enter a full vowel. Jhor selects the sign or full vowel from context and supports repeated-key vowel entry.

| Text | Goti | Jhor |
| --- | --- | --- |
| আমি | K F X C | F X L |
| কী | J T | J G |
| বই | A K C | A L L |
| তিনিই | M C S C K C | M L S L L L |
| আকাশ | K F J F Y | F J F Y |

[Practise in Typing Master](https://robispider.github.io/kala-typing-master/). Before using a Windows installation, check its on-screen keyboard: Goti has hasant on K and ি on C; Jhor has hasant on C and ি on L.
