# Kala Goti — কালা গতি

[Guide index](../../USER_GUIDE.md) · [Kala Jhor](kala-jhor.md) · [Research and full comparison](research-and-comparison.md)

**Goti (গতি)** means motion or speed. Kala Goti is a fixed Bangla layout from the **Bangla-DH Pure** research project. Its keys were arranged by computer search for lower modeled finger effort. It uses **UniJoy-style vowel entry**, with new key positions.

The current bundled layout is version **1.0**. It ranks second in the recorded eight-layout comparison: average **J1 = 1.8432**, or **34.1% less modeled effort than UniJoy**. The name and model result do not imply a measured typing-speed gain.

## Select it

1. Open Kala's **Layouts** page.
2. Find **Kala Goti** and choose **Use this layout**.
3. Open the on-screen keyboard to see the arrangement.
4. Click an editable field, turn Bangla on, and start a fresh word.

The key names below refer to the physical US QWERTY positions. `K F X C` means four separate unshifted presses. `Shift+F` is one shifted mapping. A dotted circle only helps show a combining sign and is not typed.

## Vowel signs and full vowels

Each sign has a fixed key. To produce a full vowel, press **K** (hasant) and then the sign's key. অ has its own shifted key.

## Type your first words

1. For **কি**, press **J C**: ক followed by ি.
2. For **ই**, press **K C**: ্ + ি combines to ই.
3. For **আমি**, press **K F X C**: আ + ম + ি.
4. For **বই**, press **A K C**: ব followed by the full vowel ই.
5. For **অ**, press **Shift+F**.

Goti does not automatically select a full vowel from word context. A bare C maps to the sign ি; use K C when you need ই. Unlike Jhor, two presses of the sign key are not its full-vowel recipe.

## Hasant and conjuncts

Hasant is **K**. It serves both full-vowel combinations and ordinary consonant joining:

1. For **ক্ষ**, press **J K Shift+U**: ক + ্ + ষ.
2. For **ক্র**, press **J K D**: ক + ্ + র.
3. For **ত্র**, press **M K D**: ত + ্ + র.

Enter characters in Unicode order even if a vowel sign appears visually to the left of a consonant.

## Practice words

Start each example as a fresh word. These are composition recipes; enabled correction settings and saved shortcuts can affect a word when you finish it with Space.

| Text | Keys in order |
| --- | --- |
| আমি | K F X C |
| কী | J T |
| বই | A K C |
| এবং | K L A Shift+K |
| তিনিই | M C S C K C |
| আকাশ | K F J F Y |
| ক্ষ | J K Shift+U |
| ক্র | J K D |

A short practice sequence is কি → ই → আমি → বই → আকাশ. If you already know UniJoy's vowel method, concentrate first on Goti's different physical key positions.

## Numbers, punctuation, and modifiers

The unshifted number row and numeric keypad produce Bangla digits ০–৯. Shift on the number row uses US symbols. Other mapped punctuation keys retain their US positions. Danda **।** is **G**.

Goti has normal and Shift layers. Caps changes letter mappings; leave Caps off for these examples. There is no extra AltGr layer or dedicated key for ZWNJ, ZWJ, ঽ, ॥, —, or ৳ in this version. Use another input method or paste when you need those characters.

## Goti or Jhor?

| Question | Goti | Jhor |
| --- | --- | --- |
| How do I type a full vowel? | Hasant + sign key, except অ | Context picks it; repeat the vowel key after a consonant when needed |
| Hasant key | K | C |
| Normal ি key | C | L |
| Danda key | G | T |
| Recorded average J1 | 1.8432 | 1.8000 |
| Modeled effort reduction vs UniJoy | 34.1% | 35.7% |

Goti preserves a familiar vowel-entry method; Jhor has lower effort in the recorded model. Learnability and your eventual speed need practice and measurement. The [research comparison](research-and-comparison.md) explains how both were found and why neither has a universal “best keyboard” proof.
