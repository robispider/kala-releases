# কালা গতি ও কালা ঝড়

[গাইড সূচি](../../USER_GUIDE.md) · [কালা গতি](kala-goti.md) · [কালা ঝড়](kala-jhor.md)

কালা গতি ও কালা ঝড় গবেষণাভিত্তিক বাংলা কিবোর্ড লেআউট। মডেলের হিসাবে আঙুলের পরিশ্রম কমানোর লক্ষ্য নিয়ে অক্ষরগুলোর অবস্থান বেছে নেওয়া হয়েছে। লেআউট দুটির অক্ষরের অবস্থান ও স্বরবর্ণ লেখার নিয়ম আলাদা।

## বেছে নিন ও অনুশীলন করুন

গতিতে পূর্ণ স্বরবর্ণ লিখতে হসন্তের পরে কার চাপতে হয়। ঝড়ে প্রসঙ্গ অনুযায়ী কার বা পূর্ণ স্বরবর্ণ লেখা হয়; একই অক্ষর পরপর চাপলেও পূর্ণ স্বরবর্ণ লেখা যায়।

| লেখা | গতি | ঝড় |
| --- | --- | --- |
| আমি | K F X C | F X L |
| কী | J T | J G |
| বই | A K C | A L L |
| তিনিই | M C S C K C | M L S L L L |
| আকাশ | K F J F Y | F J F Y |

[টাইপিং মাস্টারে অনুশীলন করুন](https://robispider.github.io/kala-typing-master/)। Windows অ্যাপে ব্যবহারের আগে অন-স্ক্রিন কিবোর্ডে অবস্থান মিলিয়ে নিন: গতিতে হসন্ত K-তে ও ি C-তে; ঝড়ে হসন্ত C-তে ও ি L-তে। এই পেজের আপডেট ইনস্টল করা অ্যাপ বদলায় না; [রিলিজের অবস্থা](../FEATURES_AND_RELEASES.md) দেখুন।

## গবেষণা ও লাইসেন্স
