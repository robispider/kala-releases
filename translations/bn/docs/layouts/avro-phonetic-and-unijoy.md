# Avro Phonetic ও UniJoy

[নির্দেশিকার সূচি](../../USER_GUIDE.md) · [লেআউট বেছে নেওয়া ও ইমপোর্ট করা](../03-layouts-and-import.md) · [কালা ঝড়](kala-jhor.md) · [কালা গতি](kala-goti.md)

**রিলিজের নীতি:** UniJoy/UniBijoy সঙ্গে দেওয়া হচ্ছে না। নিচের ম্যাপ গবেষণা, তুলনা ও সমর্থিত ব্যক্তিগত ইমপোর্টের রেফারেন্স। এখানে ম্যাপ থাকলেই অন্যের লেআউট বিতরণ করার অধিকার পাওয়া যায় না।


## Avro Phonetic: রোমান হরফে বানান লিখে শুরু করুন

1. **Layouts → Avro Phonetic → Use this layout** খুলুন।
2. Home-এর অনুশীলনের ফিল্ড বা অন্য অ্যাপের সম্পাদনাযোগ্য ফিল্ডে ক্লিক করুন।
3. **Ctrl + Alt + V** বা আপনার বেছে নেওয়া শর্টকাট দিয়ে বাংলা চালু করুন।
4. `ami` লিখে Space চাপুন। এরপর `bangla` লিখে দেখুন।
5. টাইপ করার সময় বাংলা আউটপুট দেখুন। পরের অক্ষর চাপলে আগের অক্ষরক্রম বদলাতে পারে।
6. ওই অ্যাপে সাধারণ রোমান হরফে লিখতে চাইলে বাংলা বন্ধ করুন।

| রোমান হরফে ইনপুট | সঙ্গে দেওয়া লেআউটের উদাহরণ |
| --- | --- |
| `ami` | আমি |
| `bangla` | বাংলা |
| `kh` | খ |
| `sh` | শ |

কিছু বড় হাতের অক্ষর আলাদা ধ্বনি তৈরি করে। উদাহরণে বড় ও ছোট হাতের অক্ষর যেমন আছে, তেমনই লিখুন। Caps/Shift শুধু দেখতে কেমন হবে তা বদলায় না। URL ও ইমেইল ঠিকানা অপরিবর্তিত রাখার জন্য কালায় আলাদা নিয়ম আছে। Space চাপলে বর্তমান সেটিংস অনুযায়ী শব্দ সংশোধন হয়।

বিকল্প বানান দেখতে **Show suggestions below the cursor** (কার্সরের নিচে সাজেশন দেখান) চালু করুন। টাইপ করে একটু থামলে অভিধানভিত্তিক সর্বোচ্চ তিনটি রোমান বিকল্প আসতে পারে। Up/Down দিয়ে বেছে Enter চাপুন বা বিকল্পটিতে ক্লিক করুন। Escape চাপলে আগের লেখা থাকে। গ্রহণ করা বানান নিজে থেকে সেভ হয় না; রাখতে চাইলে Personal words-এ আলাদা করে সেভ করুন।

Avro Phonetic-এর পরিচিত টাইপিং পদ্ধতি অনুসরণ করতে কালা তার লেআউট ও নিয়ম ব্যবহার করে। সেশন, আউটপুট যাচাই, সংশোধন ও অভিধানভিত্তিক সাজেশন কালার নিজস্ব ব্যবস্থা। তাই Avro-এর সব সংস্করণ, অভিধান বা বানান বেছে নেওয়ার আচরণের সঙ্গে হুবহু মিলের নিশ্চয়তা নেই। কোডে থাকা মূল প্রকল্প থেকে নেওয়া আলাদা পার্সারটি সাধারণ লেআউট তালিকার আরেকটি অপশন নয়।

[OmicronLab](https://www.omicronlab.com/) ও [Avro Keyboard-এর অবদানকারীদের](https://github.com/omicronlab/Avro-Keyboard) ধন্যবাদ। কালার README-তে স্বীকৃত Avro লেআউট ও নিয়মের কাজ তাঁদের প্রকল্প থেকে এসেছে।

## UniJoy: গবেষণা ও ইমপোর্ট করা লেআউটের রেফারেন্স

1. ব্যবহার করার অধিকার আছে এমন সমর্থিত UniJoy লেআউট ফাইল ইমপোর্ট করে **Use this layout** বেছে নিন।
2. কোন অক্ষর কোথায় আছে, তা দেখতে কালার অন-স্ক্রিন কিবোর্ড খুলুন।
3. একটি সম্পাদনাযোগ্য ফিল্ডে ক্লিক করে বাংলা চালু করুন।
4. নিচের ম্যাপ অনুযায়ী ফিজিক্যাল কিবোর্ডের অক্ষর চাপুন। অবস্থান বোঝাতে বড় হাতের ইংরেজি অক্ষর দেওয়া হয়েছে; Shift ধরে রাখতে হবে না।
5. হসন্ত লিখতে **G** চাপুন। পূর্ণ স্বরবর্ণ লিখতে G-এর পর সংশ্লিষ্ট কার লেখার অক্ষর চাপুন। শুধু অ-এর জন্য **Shift+F** ব্যবহার করুন।

টেবিলগুলো US QWERTY কিবোর্ডে অক্ষরের অবস্থান বোঝায়। কার ও যুক্ত চিহ্ন স্পষ্ট করে দেখাতে বিন্দুযুক্ত বৃত্ত দেওয়া হয়েছে; সেটি আউটপুটে আসে না।

## UniJoy-এ স্বরবর্ণ লেখার অক্ষর চাপার ক্রম

| পূর্ণ স্বরবর্ণ | অক্ষর চাপার ক্রম |
| --- | --- |
| অ | Shift+F |
| আ | G F |
| ই | G D |
| ঈ | G Shift+D |
| উ | G S |
| ঊ | G Shift+S |
| ঋ | G A |
| এ | G C |
| ঐ | G Shift+C |
| ও | G X |
| ঔ | G Shift+X |

ব্যঞ্জনবর্ণের পরে কার বসাতে শুধু কার লেখার অক্ষর চাপুন: **J D** থেকে কি আসে। যুক্তাক্ষরের জন্য ব্যঞ্জনবর্ণ + G + ব্যঞ্জনবর্ণ লিখুন: **J G Shift+N** থেকে ক্ষ আসে। UniJoy-এ ্র, র্ ও ্য-এর মতো একাধিক ইউনিটের রূপও দেখানো অক্ষর চেপে সরাসরি লেখা যায়।

## UniJoy অনুশীলনের উদাহরণ

Caps বন্ধ রেখে প্রতিটি উদাহরণ নতুন শব্দ হিসেবে শুরু করুন:

| লেখা | অক্ষর চাপার ক্রম |
| --- | --- |
| আমি | G F M D |
| তুমি | K S M D |
| কী | J Shift+D |
| বই | H G D |
| এবং | G C H Q |
| ক্ষ | J G Shift+N |

কালার UniJoy একটি Unicode ফিক্সড লেআউট; ANSI আউটপুট মোড নয়। গবেষণায় এই নির্দিষ্ট অক্ষর ম্যাপই ব্যবহার হয়েছে। গতি একই হসন্ত + কার পদ্ধতি রেখে অক্ষরের অবস্থান বদলেছে। ঝড়ে আগের অক্ষর অনুযায়ী স্বরবর্ণ লেখার আলাদা নিয়ম আছে।
