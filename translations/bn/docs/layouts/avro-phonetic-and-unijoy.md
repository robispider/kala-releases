## Avro Phonetic: রোমান হরফে বানান লিখে শুরু করুন

1. **Layouts → Avro Phonetic → Use this layout** খুলুন।
2. Home-এর অনুশীলনের ঘর বা অন্য অ্যাপের সম্পাদনাযোগ্য ঘরে ক্লিক করুন।
3. **Ctrl + Alt + V** বা আপনার বেছে নেওয়া শর্টকাট দিয়ে বাংলা চালু করুন।
4. `ami` লিখে Space চাপুন। এরপর `bangla` লিখে দেখুন।
5. টাইপ করার সময় গঠিত বাংলা লেখাটি দেখুন; পরের একটি কী আগের অক্ষরক্রম বদলে দিতে পারে।
6. ওই অ্যাপে সাধারণ রোমান হরফে লিখতে চাইলে বাংলা বন্ধ করুন।

| রোমান হরফে ইনপুট | সরবরাহ করা লেআউটের উদাহরণ |
| --- | --- |
| `ami` | আমি |
| `bangla` | বাংলা |
| `kh` | খ |
| `sh` | শ |

কিছু বড় হাতের অক্ষর ভিন্ন ধ্বনি বোঝায়। কী-ক্রমে দেখানো বড় ও ছোট হাতের অক্ষর ঠিক রাখুন; Caps/Shift শুধু লেখার চেহারা বদলায় না। Kala URL/ইমেইলের অক্ষরক্রমের জন্য নির্দিষ্ট নিয়ম ব্যবহার করে সেগুলো অক্ষুণ্ণ রাখে। Space চাপলে সম্পূর্ণ হওয়া শব্দে আপনার সেটিংস অনুযায়ী সংশোধন চলে।

বিকল্প বানান দেখতে **Show suggestions below the cursor** (কার্সরের নিচে পরামর্শ দেখান) চালু করে টাইপ করুন এবং একটু থামুন। অভিধানভিত্তিক রোমান বিকল্প পাওয়া গেলে সর্বোচ্চ তিনটি দেখানো হয়। Up/Down দিয়ে বেছে Enter চাপুন, অথবা একটিতে ক্লিক করুন। Escape চাপলে আপনার টাইপ করা লেখাই থাকে। এভাবে বেছে নেওয়া বানান স্বয়ংক্রিয়ভাবে মনে রাখা হয় না; পছন্দের বানান স্থায়ীভাবে রাখতে Personal words-এ আলাদা করে সংরক্ষণ করুন।

Kala Avro Phonetic-এর আচরণ অনুসরণ করতে তার লেআউট ও নিয়ম ব্যবহার করে, সঙ্গে থাকে Kala-র নিজস্ব সেশন, আউটপুট যাচাই, সংশোধননীতি ও অভিধানভিত্তিক পরামর্শ। সাধারণভাবে সরবরাহ করা লেআউটটি Avro-র প্রতিটি সংস্করণ বা অভিধানকে অগ্রাধিকার দিয়ে Avro-র বানান বেছে নেওয়ার আচরণের সঙ্গে হুবহু মিলের প্রতিশ্রুতি দেয় না। কোডে থাকা মূল উৎস থেকে নেওয়া পৃথক পার্সারটি সাধারণভাবে বেছে নেওয়ার মতো আরেকটি সরবরাহ করা লেআউট নয়।

[OmicronLab](https://www.omicronlab.com/) ও [Avro Keyboard-এর অবদানকারীদের](https://github.com/omicronlab/Avro-Keyboard) ধন্যবাদ। Kala-র README-তে স্বীকৃত Avro লেআউট ও নিয়মের কাজ তাঁদের প্রকল্প থেকে এসেছে।

## UniJoy: নির্দিষ্ট কী ব্যবহার করুন

1. Layouts-এ **UniJoy → Use this layout** বেছে নিন।
2. কোন কীতে কী আছে দেখতে Kala-র পর্দার কিবোর্ড খুলুন।
3. একটি সম্পাদনাযোগ্য ঘরে ক্লিক করে বাংলা চালু করুন।
4. নিচের মানচিত্র অনুযায়ী বাস্তব কিবোর্ডের কী চাপুন; কী-এর অবস্থান বোঝাতে বড় হাতের অক্ষর লেখা হয়েছে, এগুলোর জন্য Shift ধরে রাখতে হবে না।
5. হসন্তের জন্য **G** ব্যবহার করুন। পূর্ণ স্বরবর্ণের জন্য G চাপার পর তার কারের কী চাপুন; ব্যতিক্রম অ, যার কী **Shift+F**।

সারণিগুলো US QWERTY কিবোর্ডে কী-এর অবস্থান বোঝায়। বিন্দুযুক্ত বৃত্তগুলো সংযুক্ত চিহ্ন স্পষ্টভাবে দেখাতে ব্যবহৃত হয়েছে; এগুলো লেখায় বসে না।

## UniJoy-এ স্বরবর্ণ লেখার কী-ক্রম

| পূর্ণ স্বরবর্ণ | কী-ক্রম |
| --- | --- |
| অ | Shift+F |
| আ | G F |
| ই | G D |
| ঈ | G Shift+D |
| উ | G S |
| ঊ | G Shift+S |
| ঋ | G A |
| এ | G C |
| ঐ | G Shift+C |
| ও | G X |
| ঔ | G Shift+X |

ব্যঞ্জনবর্ণের পরে কার বসাতে শুধু কারের কী চাপুন: **J D** দিলে কি হয়। যুক্তবর্ণের জন্য ব্যঞ্জনবর্ণ + G + ব্যঞ্জনবর্ণ ব্যবহার করুন: **J G Shift+N** দিলে ক্ষ হয়। UniJoy-এ ্র, র্ ও ্য-এর মতো একাধিক ইউনিটের রূপও দেখানো কী দিয়ে সরাসরি লেখা যায়।

## UniJoy অনুশীলনের উদাহরণ

Caps বন্ধ রেখে প্রতিটি উদাহরণ নতুন শব্দ হিসেবে শুরু করুন:

| লেখা | কী-ক্রম |
| --- | --- |
| আমি | G F M D |
| তুমি | K S M D |
| কী | J Shift+D |
| বই | H G D |
| এবং | G C H Q |
| ক্ষ | J G Shift+N |

Kala-র UniJoy একটি Unicode-ভিত্তিক নির্দিষ্ট কী-লেআউট। এটি ANSI আউটপুট মোড নয়, এবং গবেষণার তুলনায় এই নির্দিষ্ট কী-বিন্যাসই ব্যবহার করা হয়েছে। Goti ভিন্ন কী-এর অবস্থান নিয়ে হসন্ত + কার পদ্ধতিটি বজায় রাখে; Jhor প্রসঙ্গভিত্তিক স্বরবর্ণের ভিন্ন নিয়ম ব্যবহার করে।
