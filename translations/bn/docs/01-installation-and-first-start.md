# ১. ইনস্টলেশন ও প্রথমবার চালু করা

[নির্দেশিকার সূচি](../USER_GUIDE.md) · [পরবর্তী: দৈনন্দিন টাইপিং](02-typing-and-apps.md)

## যা প্রয়োজন

বিতরণ করা সেটআপ প্যাকেজটি **64-bit Windows (x64)**-এর জন্য। এতে প্রয়োজনীয় .NET রানটাইম অন্তর্ভুক্ত আছে, তাই আলাদাভাবে .NET ইনস্টল করতে হবে না। সেটআপ আপনার Windows অ্যাকাউন্টের জন্য ইনস্টল করে এবং প্রশাসকের অনুমতির প্রয়োজন হয় না। এই রিলিজে অন্য অপারেটিং সিস্টেমের প্যাকেজ বা নেটিভ ARM64/x86 প্যাকেজ দেওয়া হয়নি।

এই নির্দেশিকার জন্য পর্যালোচনা করা রিলিজটি হলো **v0.1.0-alpha.1**। এটি একটি আলফা প্রি-রিলিজ; আরও নতুন সংস্করণ ইনস্টল করার আগে তার রিলিজ নোট পড়ুন।

## Kala ডাউনলোড করুন

1. [Kala-এর রিলিজ পাতা](https://github.com/robispider/kala-releases/releases) খুলুন।
2. একটি রিলিজ খুলুন এবং প্রয়োজনে **Assets** অংশটি প্রসারিত করুন।
3. রিলিজটির Kala সেটআপ `.exe` ডাউনলোড করুন। এই সংস্করণের জন্য **KalaSetup-v0.1.0-alpha.1.exe** বেছে নিন।
4. ডাউনলোড করা ফাইলের SHA-256 চেকসাম যাচাই করার জন্য রিলিজে `SHA256SUMS.txt`-ও আছে। GitHub স্বয়ংক্রিয়ভাবে যে **Source code (zip/tar.gz)** আর্কাইভ তৈরি করে, তাতে এই রিলিজ রিপোজিটরির ফাইলগুলো থাকে; সেগুলো ইনস্টলার বা অ্যাপ্লিকেশনের সোর্স কোড নয়।

বর্তমান ইনস্টলারে ডিজিটাল স্বাক্ষর নেই। Windows একটি SmartScreen সতর্কতা দেখাতে পারে। ফাইলটি চালানোর সিদ্ধান্ত নেওয়ার আগে নিশ্চিত করুন যে সেটি আনুষ্ঠানিক রিলিজ পাতা থেকে এসেছে।

## ইনস্টল করুন

1. Kala আগে থেকেই চলতে থাকলে, ট্রে আইকনে ডান-ক্লিক করে **Exit Kala (Kala বন্ধ করুন)** বেছে নিন।
2. ডাউনলোড করা সেটআপ এক্সিকিউটেবলটি স্বাভাবিকভাবে খুলুন।
3. **Welcome to Kala (Kala-তে স্বাগতম)** পাতায় **Next (পরবর্তী)** বেছে নিন।
4. **Ready to install (ইনস্টলের জন্য প্রস্তুত)** পাতায় ইনস্টলেশনের ফোল্ডারটি দেখুন: `%LOCALAPPDATA%\Programs\Kala`। ইনস্টলার এই অবস্থান নির্দিষ্ট করে রেখেছে।
5. ডেস্কটপ শর্টকাট চাইলে **Create a desktop shortcut (ডেস্কটপ শর্টকাট তৈরি করুন)** নির্বাচিত রাখুন। এই বিকল্পটি যেভাবেই রাখুন, Start Menu-তে একটি শর্টকাট যোগ হবে।
6. **Install (ইনস্টল করুন)** বেছে নিন এবং শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
7. চালু করতে **Open Kala (Kala খুলুন)** বেছে নিন। ইনস্টল করা ও চালু করা আলাদা কাজ।

সেটআপ ব্যর্থ হলে উইজার্ডে দেখানো ত্রুটিটি পড়ুন। সেটআপ লগের অবস্থান `%TEMP%\KalaSetup.log`। পুরোনো ইনস্টলেশন প্রতিস্থাপন করতে গিয়ে ব্যর্থ হলে সেটআপ আগের ইনস্টলেশন ফিরিয়ে আনার চেষ্টা করে; আবার চেষ্টা করার আগে Kala বন্ধ করুন এবং জানানো কারণটি সমাধান করুন।

## স্বাগত ধাপগুলো সম্পূর্ণ করুন

1. পরিচিতি পড়ুন এবং এগিয়ে যান।
2. ব্যবহারযোগ্য একটি লেআউট বেছে নিন। **Avro Phonetic** রোমান হরফে লেখা বানানকে বাংলায় রূপান্তর করে; **UniJoy**, **Kala Goti** এবং **Kala Jhor** নির্দিষ্ট কী-বিন্যাস ব্যবহার করে। Jhor-এ প্রসঙ্গ অনুযায়ী স্বরবর্ণের আচরণ বদলায়। এই পছন্দ পরে পরিবর্তন করতে পারবেন।
3. অনুশীলনের ঘরে ক্লিক করুন এবং Kala-তে দেখানো শর্টকাট ব্যবহার করে Kala-এর অনুশীলনের ঘরের জন্য বাংলা চালু করুন। শুরুতে শর্টকাটটি **Ctrl + Alt + V**। Avro Phonetic ব্যবহার করলে `ami bangla` লিখে দেখুন। নির্দিষ্ট কী-বিন্যাসের লেআউটের জন্য কী-মানচিত্র অনুসরণ করুন অথবা অন-স্ক্রিন কিবোর্ড খুলুন।
4. বাংলা বন্ধ করে আবার চালু করে দেখুন, যাতে মোডের পরিবর্তন চিনতে পারেন।
5. সহায়তার সেটিংগুলো বেছে নিন: **Fix clear spelling mistakes (স্পষ্ট বানান ভুল ঠিক করুন)**, **Show suggestions below the cursor (কার্সরের নিচে সাজেশন দেখান)** এবং **Remember my deliberate choices (আমার সচেতন পছন্দগুলো মনে রাখুন)**। প্রতিটি আলাদা সেটিং এবং Settings থেকে পরিবর্তন করা যায়।
6. **Start using Kala (Kala ব্যবহার শুরু করুন)** বেছে নিন।

**Skip for now (এখন বাদ দিন)** বেছে নিলে ধাপগুলো সম্পূর্ণ না করেই স্বাগত জানালা বন্ধ হয়। স্বাগত ধাপ অসম্পূর্ণ থাকলে ট্রে মেনুর **Get started (শুরু করুন)** আবার সেটি খুলবে। স্বাগত জানালা বন্ধ করলে Kala বন্ধ হয় না।

## চালু করার পর Kala খুঁজে নিন

Kala প্রথমে একটি লোডিং স্প্ল্যাশ দেখায়, তারপর ঘড়ির পাশের ট্রেতে থাকে। Windows আইকনটি লুকিয়ে রাখলে ট্রের লুকানো আইকনের অংশটি খুলুন। মূল জানালা খুলতে Kala-তে ডান-ক্লিক করে **Open Kala (Kala খুলুন)** বেছে নিন।

আবার Kala খুললে আগে থেকে চলতে থাকা কপিটিই সামনে আসে। একাধিক কপি চালু করার প্রয়োজন নেই। মূল জানালা বন্ধ করলেও Kala চলতে থাকে; **Exit Kala (Kala বন্ধ করুন)** এটিকে সম্পূর্ণ বন্ধ করে।

## Windows-এর সঙ্গে স্বয়ংক্রিয়ভাবে চালু করুন

1. Kala-এর **Settings (সেটিংস)** খুলুন।
2. **Start Kala when Windows starts (Windows চালু হলে Kala চালু করুন)** চালু করুন।
3. সাইন ইন করলে Kala চালু হবে। তবে আপনি চালু না করা পর্যন্ত বাংলা **প্রতিটি অ্যাপে বন্ধ অবস্থাতেই শুরু হয়**।

Windows যদি স্টার্টআপ অ্যাপ হিসেবে Kala-কে নিষ্ক্রিয় করে রাখে, তবে Windows-এর স্টার্টআপ অ্যাপের সেটিংও দেখুন। [সেটিংস ও সহায়তা](07-settings-privacy-and-support.md) দেখুন।

## আপডেট করুন

1. নতুন রিলিজের নোট পড়ুন এবং নতুন সেটআপ এক্সিকিউটেবল ডাউনলোড করুন।
2. ট্রে মেনু থেকে চলতে থাকা Kala বন্ধ করুন।
3. নতুন সেটআপ চালান এবং একই ব্যবহারকারীর জন্য নির্ধারিত অবস্থানে ইনস্টল করুন।
4. সেটআপ শেষ হলে Kala খুলুন।

ইনস্টলার সেটিংস, ব্যক্তিগত শব্দ এবং আমদানি করা লেআউটগুলো আলাদা `%LOCALAPPDATA%\Kala` ডেটা ফোল্ডারে রাখে। আপনার ব্যক্তিগত পছন্দগুলো গুরুত্বপূর্ণ হলে আপডেটের আগে সেগুলোর ব্যাকআপ রাখুন।

## আনইনস্টল করুন

1. Kala বন্ধ করুন।
2. Windows-এর **Settings → Apps** খুলুন এবং ইনস্টল করা অ্যাপের তালিকায় **Kala** খুঁজে নিন। Windows-এর সংস্করণ অনুযায়ী এই তালিকার নাম **Installed apps** বা **Apps & features** হতে পারে।
3. **Uninstall (আনইনস্টল করুন)** বেছে নিন এবং পরবর্তী নির্দেশনা অনুসরণ করুন।

আনইনস্টল করলে `%LOCALAPPDATA%\Kala` রেখে দেওয়া হয়, যাতে আবার ইনস্টল করলে আপনার সেটিংস ও ব্যক্তিগত পছন্দ ফিরে পাওয়া যায়। এই ডেটাও সরাতে চাইলে প্রথমে যা রাখতে চান তা এক্সপোর্ট করুন, তারপর আনইনস্টল করার পর শুধু ওই নির্দিষ্ট ফোল্ডারটি মুছুন। অন্য কোথাও এক্সপোর্ট করা কপিগুলো আলাদাভাবে থেকে যাবে।
