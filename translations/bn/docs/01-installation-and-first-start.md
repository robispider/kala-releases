# ১. ইনস্টলেশন ও প্রথমবার চালু করা

[নির্দেশিকার সূচি](../USER_GUIDE.md) · [পরবর্তী: দৈনন্দিন টাইপিং](02-typing-and-apps.md)

## যা প্রয়োজন

সেটআপ প্যাকেজটি **64-bit Windows (x64)**-এর জন্য। প্রয়োজনীয় .NET রানটাইম এতে দেওয়া আছে; আলাদা করে .NET ইনস্টল করতে হবে না। কালা আপনার Windows অ্যাকাউন্টে ইনস্টল হয়, তাই অ্যাডমিন অনুমতি লাগে না। এই রিলিজে অন্য অপারেটিং সিস্টেম বা নেটিভ ARM64/x86-এর প্যাকেজ নেই।

এই নির্দেশিকা **v0.1.0-alpha.1** সংস্করণের ভিত্তিতে পর্যালোচনা করা হয়েছে। সর্বশেষ রিলিজ <!-- kala:latest -->**v0.11.0-alpha.1**<!-- /kala:latest -->, যা একটি <!-- kala:latest-channel -->**আলফা প্রি-রিলিজ**<!-- /kala:latest-channel -->; ইনস্টল করার আগে এর রিলিজ নোট পড়ুন।

## কালা ডাউনলোড করুন

1. সর্বশেষ সেটআপ ফাইল ডাউনলোড করুন: <!-- kala:latest -->[`KalaSetup-v0.11.0-alpha.1.exe`](https://github.com/robispider/kala-releases/releases/download/v0.11.0-alpha.1/KalaSetup-v0.11.0-alpha.1.exe)<!-- /kala:latest -->।
2. ফাইলটি ঠিকমতো ডাউনলোড হয়েছে কি না যাচাই করতে <!-- kala:latest -->[v0.11.0-alpha.1 রিলিজ পেজ](https://github.com/robispider/kala-releases/releases/tag/v0.11.0-alpha.1)<!-- /kala:latest --> খুলুন এবং **Assets** তালিকার `SHA256SUMS.txt`-এর সঙ্গে ফাইলটির SHA-256 চেকসাম মিলিয়ে দেখুন।
3. পুরোনো কোনো সংস্করণ দরকার হলে [কালার রিলিজ পেজ](https://github.com/robispider/kala-releases/releases) খুলুন, রিলিজটি বেছে নিন এবং **Assets** থেকে তার কালা সেটআপ `.exe` ডাউনলোড করুন। GitHub স্বয়ংক্রিয়ভাবে যে **Source code (zip/tar.gz)** আর্কাইভ তৈরি করে, তাতে এই রিলিজ রিপোজিটরির ফাইলগুলো থাকে; সেগুলো ইনস্টলার বা অ্যাপ্লিকেশনের সোর্স কোড নয়।

বর্তমান ইনস্টলারে ডিজিটাল সিগনেচার নেই, তাই Windows-এর SmartScreen সতর্কতা দেখা যেতে পারে। চালানোর আগে ফাইলটি অফিসিয়াল রিলিজ পেজ থেকে ডাউনলোড করেছেন কি না নিশ্চিত করুন।

## ইনস্টল করুন

1. কালা আগে থেকেই চলতে থাকলে, ট্রে আইকনে রাইট-ক্লিক করে **Exit Kala (কালা বন্ধ করুন)** বেছে নিন।
2. ডাউনলোড করা সেটআপ ফাইল চালান।
3. **Welcome to Kala (কালায় স্বাগতম)** পেজে **Next (পরবর্তী)** বেছে নিন।
4. **Ready to install (ইনস্টলের জন্য প্রস্তুত)** পেজে ইনস্টলেশনের ফোল্ডার দেখুন: `%LOCALAPPDATA%\Programs\Kala`। ইনস্টলার এই নির্দিষ্ট ফোল্ডারেই কালা ইনস্টল করে।
5. ডেস্কটপ শর্টকাট চাইলে **Create a desktop shortcut (ডেস্কটপ শর্টকাট তৈরি করুন)** চালু রাখুন। এটি বন্ধ রাখলেও Start Menu-তে শর্টকাট যোগ হবে।
6. **Install (ইনস্টল করুন)** বেছে নিন এবং শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
7. অ্যাপ চালু করতে **Open Kala (কালা খুলুন)** বেছে নিন। ইনস্টল শেষ হলেই অ্যাপ চালু হয় না; এই বোতাম দিয়ে চালু করতে হবে।

সেটআপ ব্যর্থ হলে উইজার্ডের ত্রুটির বার্তা পড়ুন। সেটআপ লগ পাওয়া যাবে `%TEMP%\KalaSetup.log`-এ। পুরোনো ইনস্টলেশন বদলাতে গিয়ে সমস্যা হলে সেটআপ আগের ইনস্টলেশন ফিরিয়ে আনার চেষ্টা করে। আবার চেষ্টা করার আগে কালা বন্ধ করুন এবং দেখানো সমস্যাটি সমাধান করুন।

## প্রথমবারের সেটআপ সম্পন্ন করুন

1. পরিচিতি পড়ুন এবং এগিয়ে যান।
2. একটি লেআউট বেছে নিন। **Avro Phonetic** রোমান হরফে লেখা বানানকে বাংলায় রূপান্তর করে। **UniJoy**, **Kala Goti** ও **Kala Jhor** ফিক্সড লেআউট; ঝড়ে আগের অক্ষর অনুযায়ী কার বা পূর্ণ স্বরবর্ণ আসে। পরে লেআউট বদলাতে পারবেন।
3. প্র্যাকটিস ফিল্ডে ক্লিক করে দেখানো শর্টকাট দিয়ে বাংলা চালু করুন। ডিফল্ট শর্টকাট **Ctrl + Alt + V**। Avro Phonetic ব্যবহার করলে `ami bangla` লিখে দেখুন। ফিক্সড লেআউটের জন্য অক্ষরের ম্যাপ দেখুন বা অন-স্ক্রিন কিবোর্ড খুলুন।
4. বাংলা বন্ধ করে আবার চালু করে দেখুন, যাতে মোডের পরিবর্তন চিনতে পারেন।
5. লেখার সহায়তার সেটিংগুলো বেছে নিন: **Fix clear spelling mistakes (স্পষ্ট বানানভুল ঠিক করুন)**, **Show suggestions below the cursor (কার্সরের নিচে সাজেশন দেখান)** এবং **Remember my deliberate choices (আমার নিজে বেছে নেওয়া বানান মনে রাখুন)**। এগুলো আলাদা সেটিং; পরে Settings থেকে বদলাতে পারবেন।
6. **Start using Kala (কালা ব্যবহার শুরু করুন)** বেছে নিন।

**Skip for now (এখন বাদ দিন)** বেছে নিলে সেটআপ শেষ না করেই স্বাগত উইন্ডো বন্ধ হবে। সেটআপ অসম্পূর্ণ থাকলে ট্রে মেনুর **Get started (শুরু করুন)** দিয়ে আবার খুলতে পারবেন। স্বাগত উইন্ডো বন্ধ করলেও কালা চলতে থাকবে।

## চালু করার পর কালা খুঁজে নিন

কালা চালু হলে প্রথমে একটি স্প্ল্যাশ স্ক্রিন দেখা যায়। এরপর অ্যাপটি টাস্কবারের ঘড়ির পাশের সিস্টেম ট্রেতে চলতে থাকে। আইকন দেখা না গেলে ট্রের লুকানো আইকনগুলো খুলুন। কালার আইকনে রাইট-ক্লিক করে **Open Kala (কালা খুলুন)** বেছে নিলে মূল উইন্ডো খুলবে।

কালা চালু থাকা অবস্থায় আবার খুললে আগের উইন্ডোই সামনে আসবে; আলাদা কপি চালু হবে না। মূল উইন্ডো বন্ধ করলেও কালা চলতে থাকে। পুরোপুরি বন্ধ করতে **Exit Kala (কালা বন্ধ করুন)** বেছে নিন।

## Windows-এর সঙ্গে স্বয়ংক্রিয়ভাবে চালু করুন

1. কালার **Settings (সেটিংস)** খুলুন।
2. **Start Kala when Windows starts (Windows চালু হলে কালা চালু করুন)** চালু করুন।
3. সাইন ইন করলে কালা চালু হবে। তবে আপনি চালু না করা পর্যন্ত বাংলা **প্রতিটি অ্যাপে বন্ধ অবস্থাতেই শুরু হয়**।

Windows যদি স্টার্টআপ অ্যাপ হিসেবে কালাকে নিষ্ক্রিয় করে রাখে, তবে Windows-এর স্টার্টআপ অ্যাপের সেটিংও দেখুন। [সেটিংস ও সহায়তা](07-settings-privacy-and-support.md) দেখুন।

## আপডেট করুন

1. নতুন রিলিজের নোট পড়ুন এবং নতুন সেটআপ ফাইল ডাউনলোড করুন।
2. ট্রে মেনু থেকে চলতে থাকা কালা বন্ধ করুন।
3. নতুন সেটআপ চালান এবং একই ব্যবহারকারীর জন্য নির্ধারিত অবস্থানে ইনস্টল করুন।
4. সেটআপ শেষ হলে কালা খুলুন।

সেটিংস, ব্যক্তিগত শব্দ ও ইমপোর্ট করা লেআউটগুলো আলাদা ডেটা ফোল্ডার `%LOCALAPPDATA%\Kala`-এ থাকে। আপনার সংরক্ষিত পছন্দগুলো গুরুত্বপূর্ণ হলে আপডেটের আগে ব্যাকআপ নিন।

## আনইনস্টল করুন

1. কালা বন্ধ করুন।
2. Windows-এর **Settings → Apps** খুলুন এবং ইনস্টল করা অ্যাপের তালিকায় **Kala** খুঁজে নিন। Windows-এর সংস্করণ অনুযায়ী এই তালিকার নাম **Installed apps** বা **Apps & features** হতে পারে।
3. **Uninstall (আনইনস্টল করুন)** বেছে নিন এবং পরবর্তী নির্দেশনা অনুসরণ করুন।

আনইনস্টল করার পরও `%LOCALAPPDATA%\Kala` ফোল্ডার থাকে, যাতে আবার ইনস্টল করলে সেটিংস ও ব্যক্তিগত পছন্দ ফিরে পান। এই ডেটাও মুছতে চাইলে আগে প্রয়োজনীয় তথ্য এক্সপোর্ট করুন। তারপর আনইনস্টল শেষে শুধু ওই ফোল্ডারটি মুছুন। অন্য জায়গায় এক্সপোর্ট করা কপি আলাদা করে মুছতে হবে।
