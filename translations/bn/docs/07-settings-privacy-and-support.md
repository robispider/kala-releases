# 7. সেটিংস, গোপনীয়তা ও সহায়তা

[নির্দেশিকার সূচি](../USER_GUIDE.md) · [পরবর্তী: ঐচ্ছিক শেখার মডিউল](08-learning-module.md)

## সেটিংসের বিবরণ

Kala বা তার ট্রে মেনু থেকে **Settings** খুলুন। বদলানোর সঙ্গে সঙ্গে পরিবর্তন সংরক্ষিত হয়। সংরক্ষণ ব্যর্থ হলে সঙ্গে সঙ্গে জানানো হয়; আগের সক্রিয় সেটিং বজায় থাকে।

| বিভাগ / সেটিং | কী নিয়ন্ত্রণ করে | নতুন প্রোফাইলের ডিফল্ট |
| --- | --- | --- |
| **Typing → Layout** | সব অ্যাপে ব্যবহারের জন্য একটি প্রস্তুত লেআউট | Avro Phonetic |
| **Shortcut** | বর্তমান অ্যাপে বাংলা চালু/বন্ধ করে | Ctrl + Alt + V; বিকল্প Ctrl + Alt + B |
| **Start Kala when Windows starts** | সাইন ইন করলে Kala চালু করে | প্রতিটি ব্যবহারকারীর স্টার্টআপ নিবন্ধনের মাধ্যমে নিয়ন্ত্রিত |
| **Automatic corrections** | Space চাপলে প্রযোজ্য একক শব্দের প্রতিস্থাপন করে | চালু |
| **Show suggestions below the cursor** | লেখায় বিরতির পরে বিকল্প দেখায় | বন্ধ |
| **Pause before suggestions** | 100–5,000 ms বিলম্ব | 400 ms |
| **Extra Ctrl + Alt commands** | ঐচ্ছিক গ্রহণ/বাতিল/Undo কমান্ড চালু করে | বন্ধ |
| **Save my deliberate choices** | সচেতনভাবে আগের বানান ফিরিয়ে এনে সংরক্ষণের মতামত চালু করে | বন্ধ |
| **Mark words while I type** | লাল/সায়ান/সবুজ বানানের চিহ্ন দেখায় | বন্ধ |
| **Appearance → Interface language** | Kala-র উইন্ডোর ভাষা | English; বাংলাও অন্তর্ভুক্ত |
| **Theme** | হালকা বা গাঢ় চেহারা | Light |
| **On-screen keyboard size** | ছোট বা বড় কি | Compact |

ইন্টারফেসের ভাষা ও আপনার লেখার ভাষা আলাদা। UI বাংলায় বদলালে সব অ্যাপে বাংলা ইনপুট চালু হয় না। Windows-এর high-contrast থিম Kala-র Light/Dark পছন্দের ওপর প্রাধান্য পায়।

## চেহারা বদলান

1. **Settings → Appearance** খুলুন।
2. Interface language-এর অধীনে **English** বা **বাংলা** বেছে নিন।
3. Theme-এর অধীনে **Light** বা **Dark** বেছে নিন।
4. পর্দার কিবোর্ডের জন্য **Compact** বা **Large** বেছে নিন।

ইনস্টল করা অতিরিক্ত অনুবাদ রিসোর্স থেকে আরও ভাষা বেছে নেওয়ার সুযোগ আসতে পারে। চেহারা বদলালে লেআউট ও অনুশীলনে আপনার লেখা বজায় থাকে।

## স্টার্টআপ ও সংরক্ষিত সেটিংস

সাইন ইন করার সময় চালু করতে **Start Kala when Windows starts** চালু করুন। সেটি চালু না থাকলে ত্রুটির বার্তা ও Windows-এর startup-app নিয়ন্ত্রণ দেখুন। Windows আলাদাভাবে নিবন্ধিত স্টার্টআপ অ্যাপ বন্ধ রাখতে পারে। সাইন ইন করলে Kala নীরবে চালু হয় এবং সব অ্যাপে বাংলা বন্ধ অবস্থায় শুরু করে।

সেটিংস `%LOCALAPPDATA%\Kala\settings.json`-এ সংরক্ষিত হয়; আগের কপি থাকে `settings.json.bak`-এ। প্রধান কপি নষ্ট হলে Kala পুনরুদ্ধার করতে পারে। ফাইল পড়া না গেলে বা নতুনতর স্কিমার হলে Kala সেটি অপরিবর্তিত রাখে এবং কেন পরিবর্তন সংরক্ষণ করা যাচ্ছে না তা জানায়। হাতে ফাইল মেরামত করার আগে ডেটা ফোল্ডারের ব্যাকআপ নিন এবং আগে Kala থেকে বের হয়ে যান।

## আপনার কম্পিউটারে কী সংরক্ষিত থাকে

| স্থান | বিষয়বস্তু |
| --- | --- |
| `%LOCALAPPDATA%\Programs\Kala` | ইনস্টল করা অ্যাপ ও রানটাইম ফাইল |
| `%LOCALAPPDATA%\Kala\settings.json` | সংরক্ষিত ইন্টারফেস ও টাইপিং পছন্দ |
| `%LOCALAPPDATA%\Kala\personal` | আপনি সচেতনভাবে সংরক্ষিত শব্দ, সংশোধন, সুরক্ষা ও শর্টকাট |
| `%LOCALAPPDATA%\Kala\Layouts` | আমদানি করা লেআউট, বিকল্প ও পুনরুদ্ধারের কপি |
| `%LOCALAPPDATA%\Kala\diagnostics` | স্থানীয় ইভেন্ট কোড, সংখ্যা ও সময়ের পরিমাপ |
| `%LOCALAPPDATA%\Kala\probes` | চিহ্ন চালু থাকলে বানানের চিহ্নের ট্রেস ফাইল |
| `%LOCALAPPDATA%\Kala\learning` | আলাদা শেখার প্রোফাইল ও আমদানি করা প্যাক; কেবল Learn অন্তর্ভুক্ত বিল্ডে |
| `%TEMP%\KalaSetup.log` | সেটআপের ত্রুটি নির্ণয়ের তথ্য |

Kala আপনার টাইপিং, ব্যক্তিগত শব্দ, ত্রুটি নির্ণয়ের প্রতিবেদন বা শেখার অগ্রগতি স্বয়ংক্রিয়ভাবে আপলোড করে না। বানান যাচাইয়ের জন্য মেমরিতে রাখা লেখার প্রতিরূপ অবস্থান নির্ধারণ ও যাচাই করা সম্পাদনায় সহায়তা করতে সেশনের লেখা ধরে রাখে; এটি সংরক্ষিত টাইপিং ইতিহাস নয় এবং টাইপিং বিরত রাখলে বা চিহ্ন বন্ধ করলে মুছে যায়।

বর্তমান অ্যাপের ত্রুটি নির্ণয়ের তথ্যে টাইপ করা শব্দ, বাক্য বা পরামর্শের বদলে ইভেন্ট কোড, সংখ্যা ও সময়ের পরিমাপ থাকে। এগুলো 256 KiB-এর চারটি ফাইলের মধ্যে সীমিত এবং 14 দিন পরে মেয়াদ শেষ হয়। ব্যক্তিগত শব্দ রপ্তানির ফাইলে আপনার সংরক্ষিত শব্দ থাকে, তাই সেটিকে ব্যক্তিগত তথ্য হিসেবে রাখুন।

Kala-র পুরোনো সংস্করণ তার নির্বাহযোগ্য ফাইলের পাশে একটি `error.log` রেখে থাকতে পারে। সেই পুরোনো ফাইলে লেখা থাকতে পারে; কোনো পুরোনো ইনস্টলেশন ফোল্ডার শেয়ার করার আগে সেটি দেখুন বা মুছে দিন।

## ত্রুটি নির্ণয়ের প্রতিবেদন দেখুন

1. **Help and compatibility** অথবা Settings খুলুন।
2. **Preview diagnostics** বেছে নিন।
3. পূর্বরূপে প্রতিবেদন পড়ুন।
4. নিজে শেয়ার করতে চাইলে **Copy report** ব্যবহার করুন।
5. বিষয়বস্তু দেখে আপনার বাগ রিপোর্টে পেস্ট করুন।

Kala আপনার হয়ে প্রতিবেদন পাঠায় না। ত্রুটি নির্ণয়ের কোনো ইভেন্ট নথিভুক্ত না থাকলে পূর্বরূপে তা জানায়।

## বানানের চিহ্নের সমস্যা জানান

চিহ্ন চালু থাকলে Kala `%LOCALAPPDATA%\Kala\probes`-এ `marks-trace-<date>-<time>.txt` লেখে। এতে প্রসেসের নাম, কন্ট্রোল/অ্যাক্সেসিবিলিটির মেটাডেটা, ফ্ল্যাগ ও সংখ্যা থাকে। টাইপ করা লেখা, শব্দ ও কি এতে থাকে না। সর্বশেষ দশটি ফাইল রাখা হয়।

1. ছোট, প্রকাশ্যে শেয়ারযোগ্য উদাহরণ দিয়ে সমস্যাটি আবার ঘটান।
2. সমস্যার তথ্য রেকর্ড করার পরে Kala থেকে বের হয়ে যান বা টাইপিং বিরত রাখুন।
3. probes ফোল্ডার খুলে সর্বশেষ ট্রেস দেখুন।
4. সেটির অ্যাপ/কন্ট্রোল মেটাডেটা শেয়ার করতে স্বাচ্ছন্দ্য বোধ করলেই সংযুক্ত করুন।

## কাজে লাগে এমন মতামত দিন

Kala/রিলিজের সংস্করণ, Windows-এর সংস্করণ, অ্যাপের সংস্করণ, নির্বাচিত লেআউট, ফিজিক্যাল/পর্দার কিবোর্ড ইনপুট, সহায়তার সেটিংস এবং সমস্যাটি ঘটানোর ছোট ধাপে ধাপে বিবরণ দিয়ে একটি [Issue](https://github.com/robispider/kala-releases/issues) খুলুন। প্রত্যাশিত লেখা ও আসলে পাওয়া লেখা জানান। স্ক্রিনশট ও ত্রুটি নির্ণয়ের প্রতিবেদন ঐচ্ছিক; প্রকাশ্যে শেয়ারযোগ্য নমুনা ব্যবহার করুন এবং শেয়ারের আগে দেখে নিন।

[সুবিধার অবস্থার পৃষ্ঠা](FEATURES_AND_RELEASES.md)-তে জানা যাচাইসংক্রান্ত সীমাবদ্ধতা ব্যাখ্যা করা আছে। অনুশীলনের ঘরে সফল ফল বা ইনস্টলার বিল্ড একাই আপনার নির্দিষ্ট অ্যাপের সঙ্গে সামঞ্জস্য প্রমাণ করে না।
