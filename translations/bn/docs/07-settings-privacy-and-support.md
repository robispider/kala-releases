# ৭. সেটিংস, গোপনীয়তা ও সহায়তা

[নির্দেশিকার সূচি](../USER_GUIDE.md) · [পরবর্তী: ঐচ্ছিক শেখার মডিউল](08-learning-module.md)

## সেটিংসের বিবরণ

কালা বা ট্রে মেনু থেকে **Settings** খুলুন। পরিবর্তন সঙ্গে সঙ্গে সেভ হয়। সেভ করা ব্যর্থ হলে কালা তা জানায় এবং আগের সক্রিয় সেটিং রাখে।

| বিভাগ / সেটিং | কী নিয়ন্ত্রণ করে | নতুন প্রোফাইলের ডিফল্ট |
| --- | --- | --- |
| **Typing → Layout** | সব অ্যাপে ব্যবহারের জন্য একটি প্রস্তুত লেআউট | Avro Phonetic |
| **Shortcut** | বর্তমান অ্যাপে বাংলা চালু/বন্ধ করে | Ctrl + Alt + V; বিকল্প Ctrl + Alt + B |
| **Start Kala when Windows starts** | সাইন ইন করলে কালা চালু করে | ব্যবহারকারীর স্টার্টআপ রেজিস্ট্রেশন অনুযায়ী |
| **Automatic corrections** | Space চাপলে প্রযোজ্য একক শব্দের প্রতিস্থাপন করে | চালু |
| **Show suggestions below the cursor** | লেখায় বিরতির পরে বিকল্প দেখায় | বন্ধ |
| **Pause before suggestions** | 100–5,000 ms বিলম্ব | 400 ms |
| **Extra Ctrl + Alt commands** | ঐচ্ছিক গ্রহণ/বাতিল/Undo কমান্ড চালু করে | বন্ধ |
| **Save my deliberate choices** | আগের বানান ফিরিয়ে এনে সেভ করার অপশন চালু করে | বন্ধ |
| **Mark words while I type** | লাল/সায়ান/সবুজ বানানের চিহ্ন দেখায় | বন্ধ |
| **Appearance → Interface language** | কালার উইন্ডোর ভাষা | English; বাংলাও অন্তর্ভুক্ত |
| **Theme** | লাইট বা ডার্ক থিম | Light |
| **On-screen keyboard size** | অন-স্ক্রিন কিবোর্ডের অক্ষর ছোট বা বড় করে | Compact |

ইন্টারফেসের ভাষা এবং টাইপিংয়ের ভাষা আলাদা। UI বাংলায় করলেই অন্য অ্যাপে বাংলা ইনপুট চালু হয় না। Windows-এর হাই-কনট্রাস্ট থিম চালু থাকলে কালার Light/Dark সেটিংয়ের পরিবর্তে সেটিই ব্যবহার হয়।

## ইন্টারফেস বদলান

1. **Settings → Appearance** খুলুন।
2. Interface language-এর অধীনে **English** বা **বাংলা** বেছে নিন।
3. Theme-এর অধীনে **Light** বা **Dark** বেছে নিন।
4. অন-স্ক্রিন কিবোর্ডের জন্য **Compact** বা **Large** বেছে নিন।

অতিরিক্ত অনুবাদ রিসোর্স ইনস্টল থাকলে আরও ভাষা পাওয়া যেতে পারে। ইন্টারফেসের ভাষা বা থিম বদলালেও লেআউট ও প্র্যাকটিস ফিল্ডের লেখা থাকে।

## স্টার্টআপ ও সংরক্ষিত সেটিংস

সাইন ইনের সময় কালা চালু করতে **Start Kala when Windows starts** চালু করুন। কাজ না হলে ত্রুটির বার্তা ও Windows-এর স্টার্টআপ অ্যাপ সেটিংস দেখুন। Windows আলাদাভাবে কোনো স্টার্টআপ অ্যাপ বন্ধ রাখতে পারে। সাইন ইন করলে কালা ব্যাকগ্রাউন্ডে চালু হয়; প্রতিটি অ্যাপে বাংলা তখন বন্ধ থাকে।

সেটিংস `%LOCALAPPDATA%\Kala\settings.json`-এ সেভ হয়; আগের কপি থাকে `settings.json.bak`-এ। মূল ফাইল নষ্ট হলে কালা ব্যাকআপ থেকে ফিরিয়ে আনতে পারে। ফাইল পড়া না গেলে বা স্কিমা অ্যাপের চেয়ে নতুন হলে ফাইলটি অপরিবর্তিত রেখে সেভ করতে না পারার কারণ জানায়। হাতে এডিট করার আগে কালা বন্ধ করুন এবং ডেটা ফোল্ডারের ব্যাকআপ নিন।

## আপনার কম্পিউটারে কী সংরক্ষিত থাকে

লোকাল ডেটা, ঐচ্ছিক গবেষণার তথ্য পাঠানো, প্রকাশ্য ডেটাসেটে ব্যবহার, সংরক্ষণকাল ও মুছে ফেলার কন্ট্রোল জানতে [কালার গোপনীয়তা নীতি](privacy.md) পড়ুন।

| স্থান | বিষয়বস্তু |
| --- | --- |
| `%LOCALAPPDATA%\Programs\Kala` | ইনস্টল করা অ্যাপ ও রানটাইম ফাইল |
| `%LOCALAPPDATA%\Kala\settings.json` | সংরক্ষিত ইন্টারফেস ও টাইপিং পছন্দ |
| `%LOCALAPPDATA%\Kala\personal` | আপনি নিজে সেভ করা শব্দ, সংশোধন, সুরক্ষা ও শর্টকাট |
| `%LOCALAPPDATA%\Kala\Layouts` | ইমপোর্ট করা লেআউট, বিকল্প ও রিকভারি কপি |
| `%LOCALAPPDATA%\Kala\diagnostics` | লোকাল ইভেন্ট কোড, সংখ্যা ও সময়ের পরিমাপ |
| `%LOCALAPPDATA%\Kala\probes` | চিহ্ন চালু থাকলে বানানের চিহ্নের ট্রেস ফাইল |
| `%LOCALAPPDATA%\Kala\learning` | আলাদা শেখার প্রোফাইল ও ইমপোর্ট করা প্যাক; কেবল Learn অন্তর্ভুক্ত বিল্ডে |
| `%TEMP%\KalaSetup.log` | সেটআপের ডায়াগনস্টিক তথ্য |

কালা আপনার টাইপিং, ব্যক্তিগত শব্দ, ডায়াগনস্টিক রিপোর্ট বা শেখার অগ্রগতি নিজে থেকে আপলোড করে না। বানানের চিহ্ন ও যাচাই করা এডিটের জন্য বর্তমান সেশনের টেক্সট সাময়িকভাবে মেমরিতে রাখা হয়। এটি সেভ করা টাইপিং ইতিহাস নয়; Pause করলে বা বানানের চিহ্ন বন্ধ করলে মুছে যায়।

বর্তমান ডায়াগনস্টিক তথ্যে টাইপ করা শব্দ, বাক্য বা সাজেশন রাখা হয় না। এতে ইভেন্ট কোড, সংখ্যা ও সময়ের হিসাব থাকে। তথ্য চারটি ফাইলে রাখা হয়, প্রতিটির সীমা 256 KiB; 14 দিন পর পুরোনো তথ্যের মেয়াদ শেষ হয়। ব্যক্তিগত শব্দের এক্সপোর্ট ফাইলে আপনার সেভ করা শব্দ থাকে, তাই সেটি ব্যক্তিগত তথ্য হিসেবে রাখুন।

কালার পুরোনো সংস্করণ এক্সিকিউটেবল ফাইলের পাশে `error.log` রেখে থাকতে পারে। তাতে টাইপ করা টেক্সটও থাকতে পারে। পুরোনো ইনস্টলেশন ফোল্ডার শেয়ার করার আগে এই ফাইল দেখুন বা মুছুন।

## ডায়াগনস্টিক রিপোর্ট দেখুন

1. **Help and compatibility** অথবা Settings খুলুন।
2. **Preview diagnostics** বেছে নিন।
3. প্রিভিউতে রিপোর্ট পড়ুন।
4. নিজে শেয়ার করতে চাইলে **Copy report** ব্যবহার করুন।
5. বিষয়বস্তু দেখে আপনার বাগ রিপোর্টে পেস্ট করুন।

কালা আপনার হয়ে রিপোর্ট পাঠায় না। কোনো ডায়াগনস্টিক ইভেন্ট রেকর্ড না থাকলে প্রিভিউতে তা জানানো হয়।

## বানানের চিহ্নের সমস্যা জানান

বানানের চিহ্ন চালু থাকলে কালা `%LOCALAPPDATA%\Kala\probes`-এ `marks-trace-<date>-<time>.txt` তৈরি করে। এতে প্রসেসের নাম, কন্ট্রোল ও অ্যাক্সেসিবিলিটির মেটাডেটা, ফ্ল্যাগ ও সংখ্যা থাকে। টাইপ করা টেক্সট, শব্দ বা চাপা অক্ষর রাখা হয় না। সর্বশেষ দশটি ফাইল রাখা হয়।

1. ছোট, প্রকাশ্যে শেয়ারযোগ্য উদাহরণ দিয়ে সমস্যাটি আবার ঘটান।
2. সমস্যার তথ্য রেকর্ড করার পরে কালা থেকে বের হয়ে যান বা টাইপিং পজ করুন।
3. probes ফোল্ডার খুলে সর্বশেষ ট্রেস দেখুন।
4. সেটির অ্যাপ/কন্ট্রোল মেটাডেটা শেয়ার করতে স্বাচ্ছন্দ্য বোধ করলেই সংযুক্ত করুন।

## সমস্যা সমাধান

| লক্ষণ | করণীয় |
| --- | --- |
| বাংলার বদলে রোমান অক্ষর আসে | টেক্সট ফিল্ডে ক্লিক করুন। কালা চলছে ও Pause বন্ধ আছে কি না দেখুন। ওই অ্যাপে বাংলা চালু করে নির্বাচিত লেআউট মিলিয়ে নিন |
| ভুল বাংলা অক্ষর আসে | কোন লেআউট চালু আছে দেখুন। অন-স্ক্রিন কিবোর্ড বা লেআউটের অক্ষর ম্যাপ খুলুন |
| পুরোনো শব্দে ক্লিক করার পর ঝড়ে পূর্ণ স্বরবর্ণ আসে | কম্পোজিশন রিসেট হয়েছে। পুরোনো টেক্সট থেকে নিয়ম অনুমান না করে সংশ্লিষ্ট ব্যঞ্জনবর্ণ ও কার আবার লিখুন |
| সংশোধন হচ্ছে না | Automatic corrections দেখুন ও Space চাপুন। শব্দটি Personal words-এ অপরিবর্তিত রাখা আছে বা সঠিক হিসেবে শনাক্ত হয়েছে কি না দেখুন |
| অটোকরেকশন বন্ধ করেও শর্টকাটের লেখা আসে | শর্টকাট আলাদাভাবে কাজ করে। Personal words-এ এন্ট্রিটি এডিট করুন বা মুছুন |
| সাজেশন আসে না | সাজেশন চালু করে নির্ধারিত সময় অপেক্ষা করুন। উপযুক্ত বিকল্প বা নিরাপদ প্রতিস্থাপনের জন্য প্রয়োজনীয় কার্সর/টেক্সট রেঞ্জের তথ্য নাও পাওয়া যেতে পারে |
| বানানের চিহ্ন সরে যায় | পেস্ট, সিলেকশন, স্ক্রল, উইন্ডোর আকার বা টার্গেট বদলালে অবস্থানের তথ্য পুরোনো হয়ে যেতে পারে। নতুন টেক্সট লিখে আবার শুরু করুন |
| অন-স্ক্রিন কিবোর্ডের অক্ষর ম্লান থাকে | টার্গেট অ্যাপের নাম, বাংলা মোড, Pause এবং ফিল্ডটি সুরক্ষিত কি না দেখুন |
| অক্ষরের জায়গায় বাক্স বা ভাঙা অক্ষর দেখা যায় | অ্যাপে বাংলা সমর্থন করে এমন Unicode ফন্ট বেছে নিন। অ্যাপের টেক্সট রেন্ডারিংও যাচাই করুন |
| “Typing needs attention” | শেষ এডিট দেখে ঠিক করুন। বাংলা বন্ধ করে আবার চালু করুন, অথবা Pause করে Resume করুন। নতুন শব্দ শুরু করুন |
| কালা চালু থাকায় আপডেট ব্যর্থ হয় | ট্রে থেকে Exit Kala বেছে নিয়ে তারপর সেটআপ আবার চালান |

## সমস্যা জানানোর সময় যা লিখবেন

[Issues পেজে](https://github.com/robispider/kala-releases/issues) কালার সংস্করণ, Windows ও অ্যাপের সংস্করণ, লেআউট, ফিজিক্যাল বা অন-স্ক্রিন কিবোর্ড এবং সহায়তার সেটিংস উল্লেখ করুন। সমস্যাটি ঘটানোর ছোট ধাপ, প্রত্যাশিত লেখা এবং আসলে পাওয়া লেখা লিখুন। চাইলে স্ক্রিনশট বা ডায়াগনস্টিক রিপোর্ট দিন। প্রকাশ্যে শেয়ার করা যায় এমন নমুনা ব্যবহার করুন এবং শেয়ারের আগে তথ্য দেখে নিন।

যাচাইয়ের কোন কাজ এখনো বাকি, তা [ফিচারের অবস্থা](FEATURES_AND_RELEASES.md) পেজে জানানো আছে। প্র্যাকটিস ফিল্ডে কাজ করা বা ইনস্টলার বিল্ড সফল হওয়া দিয়ে আপনার নির্দিষ্ট অ্যাপে কাজ করার নিশ্চয়তা পাওয়া যায় না।
