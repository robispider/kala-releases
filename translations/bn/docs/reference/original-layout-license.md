# কালার নিজস্ব লেআউট: ব্যবহার করুন, বদলান, শেয়ার করুন

মালিকের **১২ অক্টোবর ২০২৬** তারিখের অনুমোদন অনুযায়ী কালার নিজস্ব **কালা ঝড় ও কালা গতি লেআউটের ম্যাপ** [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)-এর অধীনে পাবলিক ডোমেইনে দেওয়া হলো। এতে নিজস্ব অক্ষর ও লেয়ারের ম্যাপ এবং নিজস্ব স্বরবর্ণ লেখার নিয়ম অন্তর্ভুক্ত।

CC0-এর শর্ত অনুযায়ী অনুমতি চাওয়া বা লেআউটের রয়্যালটি দেওয়া ছাড়াই ব্যবহার, পরিবর্তন ও শেয়ার করতে পারবেন; বাণিজ্যিক কাজেও অন্য কিবোর্ডে যুক্ত করতে পারবেন। সম্পূর্ণ শর্ত এবং প্রয়োজন হলে প্রযোজ্য বিকল্প লাইসেন্স জানতে [মূল আইনি শর্ত](https://creativecommons.org/publicdomain/zero/1.0/legalcode.en) পড়ুন।

এটি প্রকল্পের নিজস্ব লেআউটের জন্য প্রযোজ্য। কালা অ্যাপের কোড, অভিধান, ডেটাসেট, অন্যের ইঞ্জিন, ইমপোর্ট বা তুলনার লেআউট, ব্র্যান্ডের চিহ্ন এবং অন্যের অধিকারের শর্ত বদলানো হচ্ছে না। কালা সফটওয়্যারের বিদ্যমান নোটিশ অনুযায়ী ব্যবহার ও বিতরণ বিনা মূল্যে করা যায়; সোর্স প্রকাশের পরিকল্পনা আলাদা।

UniJoy/UniBijoy রিলিজের সঙ্গে দেওয়া হচ্ছে না। এর গবেষণার রেফারেন্স এই CC0 ঘোষণার আওতায় পড়ে না।
